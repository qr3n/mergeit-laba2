# Управление заказами

Консольный проект на C++17. Для сборки нужны компилятор C++17 и CMake 3.16 или новее.

```bash
cmake -S . -B build
cmake --build build
./build/orders
(cd build && ctest --output-on-failure)
```

Демонстрация выводит результаты пяти сценариев в стандартный поток вывода. Журнал операций поступает в стандартный поток ошибок. Архитектура и результаты приведены в [отчёте](REPORT.md).
